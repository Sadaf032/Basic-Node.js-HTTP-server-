# Basic Node.js HTTP Server 🚀

A basic HTTP server built using **Node.js core modules** without using any framework like Express.js.

This project demonstrates Node.js fundamentals including the **HTTP module, File System (fs) module, routing, and npm package configuration**.

## 📌 Project Overview

This server handles multiple routes and performs different operations such as displaying web pages, showing the current time, writing data into a file, and reading file content.

## ✨ Features

- Built using Node.js native `http` module
- Custom routing without Express.js
- File writing using `fs.writeFile()`
- File reading using `fs.readFile()`
- Multiple route handling
- 404 error handling
- npm scripts configuration using `package.json`

## 🛠️ Technologies Used

- Node.js
- JavaScript
- HTTP Module
- File System Module (fs)
- npm
